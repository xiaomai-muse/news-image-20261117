A program that draws one image summing up the world news of Tuesday 17 November 2026: six stories (markets rout, Crimea bridge drone raid, Xi-Trump-Putin summit, Optimizely supply-chain hack, Hormuz tanker attack, FAA air chaos) plus a news ticker. Pure Python 3 standard library; the poster is drawn programmatically at runtime, so the output is fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
